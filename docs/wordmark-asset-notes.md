# 워드마크 로고 자산 확인 기록

제공된 가로형 PNG 원본은 728×180px 비율의 워드마크입니다. 왼쪽에는 청록·파랑 계열의 육각형 심볼이, 오른쪽에는 `ISANG ENG` 및 국문 태그라인이 함께 구성되어 있습니다. 헤더와 푸터에서는 기존 심볼 및 별도 텍스트를 제거하고 이 워드마크 전체 이미지를 사용합니다.

개발 미리보기에서 헤더와 푸터를 확인했습니다. 헤더에는 흰색 배경을 적용해 어두운 히어로 이미지 위에서도 워드마크 글씨가 선명하게 보이도록 했고, 푸터도 밝은 배경 안에서 동일한 워드마크 전체가 표시됩니다.

사용자 요청에 따라 이후 헤더와 푸터의 흰색 배경·여백 박스와 그림자를 제거했습니다. 현재 워드마크는 이미지 원본의 투명 배경을 그대로 사용합니다.
